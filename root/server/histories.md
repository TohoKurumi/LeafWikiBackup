# 历史
>好像没多少好写的（

本服务器是继承自下北泽1.0生存服务器周目（2020/01/17--2020/03/17），于2020/07/23在网易移动端租赁服平台再次开创的2.0新周目，至今未换档。

- 2020年7月23日租赁服由 YZ150 创建并一直续费维护。

- 2024年4月使用 [Fastbuilder/Phoenix](<https://github.com/DreamOneX/PhoenixBuilder/blob/main/README-cn.md>) 导入导出辅助工具（现已停止维护与服务 2018--2024/12/30）将重要活动区域（不包含下界末地）导出至国际基岩版，并托管于阿里云轻量应用服务器（2H4G4Mbps）使用 Windows Server 2019 继续开服（2024/08/22）。

- 2025年8月22日阿里云轻量云服务器到期且续费昂贵，遂转移至腾讯云轻量应用服务器（4H4G3Mbps），继续使用 Windows Server 2019。11月1日粗略地恢复了由网易版转档而来造成的群系损坏。

- 2026年7月14日为避免继续缴纳高额的续费，将服务端目录转移至腐竹捡垃圾组装的电脑上继续运行，使用 Windows Server Core 2019，未到期的腾讯云轻量应用主机被用来当作内网穿透的公网转发服务器并新部署了双群互通机器人。

- 2026年8月25日腾讯云轻量云（4H4G3Mbps）服务器到期，在腾讯云上重新购置轻量云（2H4G5Mbps）服务器当作内网穿透服务器并重新部署互通机器人。因大陆域名解析提供服务需要备案，9月7日将本维基单独内网穿透至新购置的香港云主机（2H1G10Mbps）。
