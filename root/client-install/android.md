 # Android
<br>

Android 8 以下的安卓版本 Mojang 明确说明不再提供支持，若你的安卓版本低于该版本且执意要下载安装可能会有未知的风险。若你未购得正版可尝试以下提供的 MCAPKS 下载站或 LeviLaunchroid 启动器去验证版。

推荐使用启动器，LeviLauncher 安卓版支持版本隔离与内容管理（附加包，皮肤包，存档等），同时支持安装 Levilamina 专有客户端模组。但需要注意的是因为平台差异，Windows Levilamina 模组和 Android Levilamina 模组并不通用。
