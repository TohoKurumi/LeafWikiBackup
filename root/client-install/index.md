# 概述
<br>

**迄今为止Mojang已经使基岩版能够运行在各种平台上并能够一起联机，其中有官方支持的平台 Windows、Xbox、Android、iOS 等，也有官方不支持的平台如 macOS，GNU/Linux 等。有趣的是，即使官方不支持，部分平台也有办法运行基岩版。**

目前支持的客户端版本（BE）：1.26.20.04（另名26.2004、26.20等），以下的页面提供了各个平台的下载安装方法。
