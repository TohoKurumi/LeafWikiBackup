# ⚠ Unlock Minecraft
> 仅供参考，请支持正版。
>[Windows 正版（JE&BE）](https://apps.microsoft.com/detail/9NXP44L49SHJ?hl=zh-hans&gl=US&ocid=pdpshare)
> 
> ---

 ## Windows
 ### 一、BedrockBoot 启动器插件解锁：
打开 BedrockBoot 点到下载选项，可以看到有一个名为 BedrockBoot Pro 的插件，若没有可以搜索此插件名。安装此插件，插件可以在 设置-插件-管理 中进行管理。随后启动游戏便可以正常玩了。本启动器也可以在最初的引导中选择其他启动器的内容路径以解锁其他启动器安装的实例版本。
<img src="/assets/v2-JwLUDR/image.png" width="335">

<br>

### 二、CookiesMinecraft 解锁：

此解锁方法会修改系统配置和文件，请严格按步骤执行，出现意外概不负责。

解锁前：<img src="/assets/v2-JwLUDR/locked.png" width="335">
解锁后：<img src="/assets/v2-JwLUDR/unlocked.png" width="335">

准备：CookiesMinecraft 解锁程序，关闭 Windows Defender 注册表项文件。以上工具都上传至网盘可供下载。

网盘链接: <https://haeigdt.lanzouq.com/b01euptexi> 密码: `acmk`

 1. Windows Defender 会把 CookiesMinecraft 识别为恶意软件并隔离，因此需要先干掉它。双击下载和解压好的注册表文件 close windows defender.reg，弹出的窗口点击“是”。
<img src="/assets/v2-JwLUDR/regedit.png" width="335">
2. 随后**重启电脑**，打开 Windows 安全中心查看“病毒和防威胁防护”应该是关闭状态。
<img src="/assets/v2-JwLUDR/closewd.png" width="335">
3. 双击下载好的安装程序 CookiesMinecraft V3.6 Installer，按1回车，看见 [SUCCESS] 代表安装成功。
<img src="/assets/v2-JwLUDR/installing.png" width="335">
4. 此时桌面上应多出一个 CookiesMinecraft 的快捷方式。双击打开。
<img src="/assets/v2-JwLUDR/shortcut.png" width="335">
5. 出现 STARTUP 界面按1回车。
<img src="/assets/v2-JwLUDR/startup.png" width="335">
6. 随后来到菜单页面，可以看到绿色的字符画 COOKIESMINECRAFT。再按1回车以选择第一选项（Install Bypass）。
<img src="/assets/v2-JwLUDR/bypass.png" width="335">
7. 出现的免责声明按任意键跳过，来到 CHOOSE COOKIES DLL 选择界面，两个选项其实都可以选，这里按1回车。
<img src="/assets/v2-JwLUDR/selectoptions.png" width="335">
8. 输出若全是绿色的 [SUCCESS] 代表成功。此时再启动游戏就没有试玩界面了。
<img src="/assets/v2-JwLUDR/success.png" width="335">
9. 若输出 [ERROR] Destination folder is invalid or is not a Minecraft folder: C:\…\… 的红色报错信息请重新前往步骤 6. 的菜单界面，按4回车（Change Minecraft folder）来更改游戏文件所在路径。
<img src="/assets/v2-JwLUDR/error.png" width="335">
10. 我们需要找到 Minecraft 的程序所在路径，对于无启动器单版本，可以右键游戏的桌面快捷方式→打开文件所在位置找到。对于启动器，以 LeviLauncher 为例，点击主页面的绿色启动按钮旁的齿轮按钮，在展开的 UI 点击打开游戏安装目录可以找到，
<img src="/assets/v2-JwLUDR/openfolder.png" width="335">
    <img src="/assets/v2-JwLUDR/openfolderlevi.png" width="335">
11. 在打开的路径下确认是否有名为 Minecraft.Windows 的应用程序，若有便复制资源管理器地址栏上的路径。
<img src="/assets/v2-JwLUDR/copy.png" width="335">
12. 回到 CookiesMinecraft，把复制的路径粘贴进对话框后回车，看见 [SUCCESS] 后按任意键回车，来到菜单界面从步骤 6. 重新开始就好了。
<img src="/assets/v2-JwLUDR/paste.png" width="335">
