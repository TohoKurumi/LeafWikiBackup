# Windows
<br>

请确保 Windows 版本至少为 Win10 18362 及以上，可以在 [MCAPPX 版本库](<https://www.mcappx.com/bedrock/26.20/26.20>) 中查询自己的 Windows 版本和架构，确保系统能正常使用 Xbox（Gaming Services） 和 Microsoft Store 相关服务。

推荐使用启动器，以下推荐的多个启动器都支持版本隔离，内容管理（资源包、行为包、皮肤包等），CurseForge 及其他资源下载入口和 dll 注入（或Mod加载器）等功能。

##  一、Levilauncher 启动器 (推荐) 

- **特色**：支持 Levilamina 加载器的客户端模组，服务器列表管理，集成 Bedrinth（LL 模组专用平台）、CurseForge 资源下载入口和编辑存档元数据等功能。具体可参阅下面链接和 github 项目主页。

  **官网链接**：<https://levilauncher.levimc.org/zh-CN>

  **项目链接**：<https://github.com/LiteLDev/LeviLauncher>

  **教程**：

  - 从 GitHub 或蓝奏云下载 `LeviLauncher-amd64-installer.exe`，下载完后双击运行，选择适合自己的安装路径，安装完后双击桌面的 LeviLauncher 快捷方式，首次打开会让配置内容路径，这是版本隔离的目录，选默认的就行了。
<img src="/assets/_Yp_1asDR/ping-mu-jie-tu-11-edit-1.png" width="339.6">
  - 点击左侧下载选项卡，下载列表内找到版本1.26.20.4,并下载，右上角的下载管理可以查看下载进度。
<img src="/assets/_Yp_1asDR/picsart-08-20-08-36-27.jpg" width="339.6">
  - 下载完成后回到原来的版本下载列表会显示“安装”，点击安装。
<img src="/assets/_Yp_1asDR/picsart-08-20-08-38-54.jpg" width="339.6">
  - 安装界面会有个安装 Levilamina 的选项，如果你想使用 Levilamina 客户端模组（LL 模组如小地图，投影等）推荐打开。
<img src="/assets/_Yp_1asDR/picsart-08-20-09-43-43.jpg" width="339.6">
  - `lip` 是 levilamina 的模组包管理器，如果提醒 `lip` 未安装可以按提示下载安装。安装完后就可以启动游戏了。
<img src="/assets/_Yp_1asDR/picsart-08-20-09-37-25.jpg" width="339.6">

  **参考链接**：<https://levilauncher.levimc.org/zh-CN/guide/requirements-installation>，此链接有更详细的 LeviLauncher 使用教程。

## 二、BedrockBoot 启动器
- **特色**：绿色软件，支持 Windows 和 Linux，支持下载与启动 UWP 版本，PaperConnect 联机服务抛弃传统的 Xbox 联机，兼容其他启动器， Java 版资源包转换基岩版等功能。具体可参阅下面链接和 github 项目主页。

  **官网链接**：<https://bb.roundstudio.top>

  **项目链接**：<https://github.com/Round-Studio/BedrockBoot> 

  **教程**：

  - 进入 github 发行页，Windows 系统下载 exe 后缀的文件。由于是绿色软件，下载完的软件可以移动到桌面，或移动到自己记得的路径并创建快捷方式。
<img src="/assets/_Yp_1asDR/kuaijie.png" width="339">
  - 若出现 `.NET` 运行时依赖报错，按指引下载然后安装就好了。
<img src="/assets/_Yp_1asDR/yilai.png" width="339">
  - 首次启动会有引导界面，在“导入”这个步骤若你有来自其他启动器的内容路径配置可以选择导入，若没有可以选一个好记的路径作为内容目录。
<img src="/assets/_Yp_1asDR/shouciqidong.png" width="339">
  - 点击下侧的下载图标选项卡，展开版本列表，滚轮往下滑找到版本1.26.2004并下载。
<img src="/assets/_Yp_1asDR/xiazai.png" width="339">
  - 右上角可以查看下载进度，下载完成后会自动安装，然后就可以启动游戏了。
<img src="/assets/_Yp_1asDR/jindu.png" width="339">

  **参考链接**：<https://docs.roundstudio.top/docs/product/bb>
