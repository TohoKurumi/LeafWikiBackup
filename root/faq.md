## GitHub 下载慢？
- Windows：

  使用 Steam302 加速器 <https://www.dogfight360.com/blog/18682>

  下载 AMD 架构（常用）的压缩包后，解压到自己熟悉的路径，可以创建快捷方式到桌面。打开后勾选 Github，启动加速器即可。
<img src="/assets/ikV-_AUvg/picsart-08-20-09-59-10.jpg" width="339">

- Android：

  使用 VPN 

  原子加速器聚变版（更多节点） <https://atomdn.duckdns.org/amf.apk>

  原子加速器普通版（备用） <https://svc955.github.io/>

  聚变版获取加速包点击左上角的“≡”，点击设置，点击加速包，按提示点击跳转到广告，15秒后切回加速器，叉掉广告即可获得加速包解锁所有节点。
  <img src="/assets/ikV-_AUvg/screenshot-20260904-151016.png" width="200">
